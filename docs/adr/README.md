# Architecture Decision Records

Vazio por enquanto. Um ADR só entra aqui quando a decisão for:

1. difícil de reverter;
2. surpreendente sem contexto para quem ler depois;
3. resultado de um trade-off real entre alternativas.

Decisões de produto (invariantes, regras de domínio) ficam em `project-contract.md`, não aqui.
